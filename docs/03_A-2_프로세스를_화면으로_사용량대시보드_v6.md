### 0-b. 주요 내부 로직 (각 1줄)

(v5 와 동일, ★ 표시 v6 변경/신규)

- **인증 도메인 화이트리스트**: `ALLOWED_EMAIL_DOMAINS` 미일치 → `/login?error=domain`.
- **어드민 판정**: `ADMIN_EMAIL`. 어드민만 `/member` + `/team/[userId]/dashboard` + 팀 페이지 Engagement/Top Sessions.
- **API 키 발급**: `/api/cli-auth?port=9988` → 32바이트 hex + sha256 해시 DB → `127.0.0.1:9988` 리다이렉트.
- **데이터 수집 스케줄**: macOS launchd `StartInterval 7200s`. Windows Task Scheduler 0/6/12/18 + `StartWhenAvailable=true`.
- **수집 페이로드**: codeburn x5 + ccusage daily, allSettled 600s → POST `/api/ingest`.
- **ccusage 머지**: incoming 비고 prev 있으면 prev 보존.
- **Boundary 감지**: today.period 정규식. timezone NULL OK.
- **Snapshot 승격 + Retention**: weekly 5주 / monthly 12달 / daily 7일.
- **Period 필터**: today / month / 8days / 30days / all.
- **Heatmap 길이 적응형**: clamp(15, ceil(데이터일수/7), 26).
- **★ 활동 heatmap 임계 (v6 갱신)**: 0 / <$5 / <$25 / <$100 / $100+ — 외부 (Anthropic 평균 $6, 엔터 active 평균 $13, 엔터 90th $30) + 내부 (p50 $21, p90 $154) + 사용자 직감 ("$100 = 엄청") 3중 검증. legend `$0 / $100+`.
- **효율 등급**: 6 메트릭 × 5단계, 종합 = cache×0.4 + 1shot×0.4 + cost×0.2.
- **stale 멤버 필터**: rawJson today/month daily[0].date ≠ 현재 UTC → 0 처리.
- **DashboardView 자동 분기**: !lastSyncedAt && !viewOnly → /setup. !overview → sync 명령.
- **Setup-status fetch 실패**: 에러 화면 + [다시 시도].
- **Visit 카운트 + Dwell 추적**: mount POST /api/visit (count++), visibility-API → sendBeacon /api/visit-end (dwell+=sec). session.user 만 카운트, 4시간 cap.
- **체류 heatmap**: visitDaily 의 dwellSec → 분 단위 + 5단계 (0/<2/2-5/5-15/15+). 카드 라벨 inline "이번달 N회 방문 · 평균 M:SS".
- **Team Engagement 컬럼** (어드민 only): /api/team monthVisits + avgDwellSec 응답. /team Last Sync → Engagement 카드. 0회 red / 1-3회 yellow.
- **★ Industry Comparison (v6 신규)**: /api/team 응답 `industryComparison` — 최근 30일 active day 분포 percentile (p50/p75/p90/max + avg) + 멤버별 30일 합 (perDevMonthAvg/Max). 데이터 source: ccusage daily 우선, 없으면 codeburn all.daily. 외부 (Anthropic / 엔터 / ccusage) hardcoded 비교 표 + 우리 팀 라이브. /team 맨 아래 Row 7. 모든 멤버 노출. 푸터 "⚡ Primus 는 엔터 active day 평균 ($13) 대비 N.N배 — Claude Code 적극 활용 팀".
- **CLI ownership preflight**: install.sh 4 위치 root 검사 + .pkg Node nvm 권유.
- **stale 임계 (마지막 데이터 수신 후 경과 시간)**:
  - setup-status: ≥ 24h (= 1440분) → 노란 ⚠ "수집이 멈췄을 수 있어요" 박스.
  - team SyncBadge: ≥ 2일 → yellow `2일전`, ≥ 5일 → red `⚠N일`.
  - 응답 stale 필터: rawJson today/month daily[0].date ≠ 현재 UTC 일자/월 → cost/sessions 0 처리.
- **fetch 실패 UX (모든 데이터 화면 일관)**:
  - setup, dashboard, team, setup-status: API 응답 500 또는 network fail 시 에러 박스 + "다시 시도" 버튼 (sync-needed/loading 과 별도 UX). 재시도 버튼 클릭 시 reload key 증가 → useEffect 재실행.
  - 멤버 프로필 (`/team/[userId]`):
    - API 404 (user 없음) → "⚠ 멤버를 찾을 수 없어요" + 팀랭킹 복귀 버튼.
    - user 있고 snapshots 0 (sessionsCount=0 + daily 0) → "아직 데이터가 없어요" 단일 메시지.
    - 그 외 → 정상 (summary/heatmap/projects).
  - team fetch 실패 → 페이지 전체 fetch error 박스 (industry card 만 미렌더가 아니라 전체).

#### 4-b. UX 의도

- **모든 멤버 노출 (어드민 only 아님)**: Row 7 의 본질 = 모럴 부스트 + 팀 정체성. 어드민이 자기 자료로만 보면 가치 없음. 멤버가 자기 dashboard 효율 등급 "보통" 받아도 "근데 우리 팀은 외부 평균 5배 위" 라는 절대 기준 인지 → 자신감 회복.
- **외부 hardcoded + 우리 팀 라이브**: 외부 출처 (Anthropic / 엔터 / ccusage) 는 안정적이라 hardcoded. 우리 팀 통계는 매일 변하므로 라이브. 30일 윈도우라 변동 적당히 smoothing.
- **30일 active day 기준 선택 이유**: 외부 강한 신호가 "엔터 active day 평균 $13" + "월간 $150-250" → 동일 단위 비교 가능. 8일 윈도우는 단발 변동에 흔들림 (단일 $500 day 가 평균 비현실 띄움). all-time 은 오래된 패턴 (1월 도구 적응기) 섞임. 30일이 sweet spot.
- **multiplier "N.N배"**: 엔터 active day 평균 $13 대비. 직접 비교 (active day vs active day). Anthropic $6 대비면 더 큰 숫자 (10배~) 가 나오지만 비교 단위 모호 (per user vs per active day). $13 이 가장 정직.
- **emerald 톤**: 다른 카드 (cyan/yellow/red 등) 와 구분 — "특별한 카드". 푸터 emerald-950/20 배경으로 punchline 강조.
- **"Primus vs 업계" 라벨 (사실 기반)**: "헤비 유저 클럽" 같은 강조보다 정직. 매주 보는 멤버에게 식상하지 않음.
- **"활용 팀" punchline 톤**: "헤비" 보다 "적극 활용". cost concern 시 reframe — "낭비 아니라 적극 활용" 으로 답변 가능.
- **as of 2026-05 명시**: 외부 데이터 출처가 시간이 지나면 stale 가능. 분기 1회 외부 숫자 갱신 권장.
- **active day count = N 표시**: "active day 234개" 같이 데이터 기반임을 시각적으로 강조 — 헛소리 통계 아닌 라이브 데이터 기반.

## 적대적 압박 — Kill 할 이유 3개

A-2 v6 단계의 Kill 이유는 **수렴 후 남은 미세 우려 + 외부 데이터 신뢰도**.

1. **외부 출처 stale 위험**:
   - hardcoded "as of 2026-05" — Anthropic 가격 인상 / 엔터 데이터 갱신 시 정합성 깨짐
   - 분기 1회 외부 숫자 수동 갱신 권장하나 잊을 가능성 높음
   - 자동 fetch 솔루션은 over-engineering (외부 통계 API 없음, 보고서 스크래핑 fragile)
   - 백로그: A-2 갱신 트리거에 "외부 출처 6개월+ stale" 추가

2. **multiplier 가 "엔터 active day $13" 만 사용**:
   - Anthropic 평균 $6 대비면 9-10배, 엔터 평균 $13 대비면 4-5배 — 다른 인상
   - "$13 이 직접 비교" 라는 우리 결정은 합리적이나 "$6 대비 10배" 가 더 모럴 부스트 강함
   - 두 multiplier 모두 표시 가능 (하단 "Anthropic 대비 N배 / 엔터 대비 M배") — v6.1 검토

3. **/team 카드 외부 멤버 노출 위험 (slack 캡쳐 등)**:
   - 사내 OAuth 라 직접 노출 0 이지만 캡쳐는 가능
   - "우리 팀 5배 헤비" 가 Anthropic / 외부 회사에 알려지면 cost benchmark 재조정 자료로 사용될 가능성
   - 보안적 대응 X — 사내 도구 자체가 그런 수준의 정보 공유 환경. 별 우려 아님.

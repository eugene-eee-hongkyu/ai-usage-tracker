# AI Usage Tracker — 설치 가이드 (노션 페이지 초안)

> 이 문서는 노션·사내 위키에 그대로 붙여넣을 수 있는 사용자 가이드 초안.
> 마크다운으로 작성. 노션 가져오기 시 자동 변환.

---

## 30초 요약

운영체제에 맞는 방법을 선택하세요:

| 환경 | 방법 | 시간 |
|------|------|------|
| **macOS** | 인스톨러(zip) 다운로드 → 압축 해제 → 더블클릭 | 약 1분 |
| **Windows** | `.bat` 다운로드 → 더블클릭 | 약 1분 |
| **개발자·자동화** | 터미널 한 줄 (`curl ... \| bash`) | 약 30초 |

설치 후 Claude Code 세션이 끝날 때마다 자동으로 사용량이 수집됩니다.

---

## macOS

### 절차

1. 인스톨러 다운로드: [Install-AI-Usage-Tracker-Mac.zip](https://ai-usage-tracker-web-psi.vercel.app/Install-AI-Usage-Tracker-Mac.zip)
2. Finder 에서 zip 더블클릭 → 자동으로 `Install-AI-Usage-Tracker.command` 파일이 생성됨
3. `.command` 파일을 더블클릭

### 처음 실행 시 보안 경고가 뜨면

macOS Gatekeeper 가 "확인된 개발자가 아님" 경고를 띄울 수 있습니다.

**우회 방법** (한 번만 하면 됨):
1. Finder 에서 `Install-AI-Usage-Tracker.command` 를 **우클릭** (또는 Control+클릭)
2. **열기** 선택
3. 다시 "확인된 개발자가 아닙니다" 창에서 **열기** 클릭

### 실행 후

- 터미널 창이 자동으로 열림
- 설치 스크립트가 자동으로 다운로드되어 실행됨
- 중간에 GitHub 또는 Google 로그인 브라우저가 자동으로 열림 → 로그인하면 끝
- "✅ 완료되었습니다" 메시지 뜨면 터미널 창을 닫아도 됨

## Windows

### 절차

1. 인스톨러 다운로드: [Install-AI-Usage-Tracker.bat](https://ai-usage-tracker-web-psi.vercel.app/Install-AI-Usage-Tracker.bat)
2. 다운로드된 `.bat` 파일 더블클릭

### 처음 실행 시 SmartScreen 경고가 뜨면

Windows Defender SmartScreen 이 "PC를 보호했습니다" 경고를 띄울 수 있습니다.

**우회 방법** (한 번만 하면 됨):
1. **추가 정보** 클릭
2. **실행** 버튼 클릭

### 실행 후

- cmd 창이 자동으로 열림
- PowerShell 설치 스크립트가 자동으로 실행됨
- 중간에 GitHub 또는 Google 로그인 브라우저가 자동으로 열림 → 로그인하면 끝
- "[OK] 완료되었습니다" 메시지 뜨면 cmd 창을 닫아도 됨

## 개발자·자동화 (터미널)

### macOS / Linux

```bash
curl -fsSL https://ai-usage-tracker-web-psi.vercel.app/install.sh | bash
```

### Windows (PowerShell)

```powershell
irm https://ai-usage-tracker-web-psi.vercel.app/install.ps1 | iex
```

### npx 직접 (Node 22+ 이미 있으면)

```bash
npx --yes github:eugene-eee-hongkyu/ai-usage-tracker init
```

설치가 끝나면 [https://ai-usage-tracker-web-psi.vercel.app/dashboard](https://ai-usage-tracker-web-psi.vercel.app/dashboard) 에 접속하세요.

- 안 잡히면 [/setup-status](https://ai-usage-tracker-web-psi.vercel.app/setup-status) 에서 진단 카드 확인

## 자주 묻는 질문

### Q. 데이터가 안 들어와요

1. [/setup-status](https://ai-usage-tracker-web-psi.vercel.app/setup-status) 에서 마지막 sync 시각 확인
2. 환경 진단 카드의 위험 신호 확인 (Node 22 미만 / .pkg installer / npm 권한 등)
3. 터미널에서 한 줄 실행:
   ```bash
   npx --yes github:eugene-eee-hongkyu/ai-usage-tracker repair
   ```
4. 그래도 안 되면 #usage-tracker 채널에 문의 (또는 사내 담당자에게)

### Q. "npm permission denied" 같은 권한 에러가 떠요

- 시스템 Node + 과거 sudo 흔적 때문일 가능성 높음
- 새 cli (`npx … repair`) 가 자동 복구 prompt 를 띄움 — **Y** 만 누르면 됨
- nvm + Node 22 로 자동 전환됨 (시스템 Node 는 보존)

### Q. 내 데이터는 어디까지 보이나요?

- 팀원에게 보이는 것: 본인 cost·사용량·효율 점수
- 매니저에게 추가로 보이는 것: 본인 활성도 (방문 횟수·체류 시간)
- 비공개: 본인 5개 룰 기반 개선 제안 (본인만 봄)
- **수집 안 함**: 코드 내용·프롬프트·Claude 응답 텍스트 (메타데이터만)

### Q. Windows 에서 작동 안 해요

- 현재 SessionEnd hook 발화 검증이 macOS / Linux 우선
- 설치는 되지만 자동 수집이 일부 환경에서 안 될 수 있음 — 관찰 중

### Q. 환경 진단을 한 번에 확인하고 싶어요

터미널에서:
```bash
npx --yes github:eugene-eee-hongkyu/ai-usage-tracker doctor
```

JSON 으로 출력하려면 `--json` 추가.

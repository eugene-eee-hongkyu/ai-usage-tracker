## ✨ 새 기능

- **AI Usage Tracker 첫 버전 출시.**
- **자동 데이터 수집 파이프라인** — `launchd` (Mac) / Task Scheduler (Windows) 로 일정마다 자동 sync.
- **개인 대시보드** — 일별 사용량·비용·세션 수.
- **세션 종료 hook (Claude Code SessionEnd)** — 세션 끝나면 즉시 수집.
- **Snapshot 누적** — period_snapshots 테이블로 시간 단위 보존.

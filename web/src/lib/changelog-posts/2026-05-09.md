## ✨ 새 기능

- **Active Blocks 카드** — Claude Code 의 5시간 빌링 블록을 시각화.
- **일일 효율 점수 + 90일 잔디** — 매일의 효율을 한눈에. GitHub 잔디 스타일.
- **Cache 90% streak** — cache hit 90% 이상 연속일 추적.
- **팀 랭크 카드** — 팀 내 본인 위치.
- **팀 헤드라인 카드** — 최근 30일 팀 효율 점수 + 업계 비교.

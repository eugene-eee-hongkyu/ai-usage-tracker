## ✨ 새 기능

- **Plan Health 카드** — 현재 Plan (Pro / Max5 / Max20) 추정 + 사용 한도 대비 활용도 + 권장 액션. admin 은 멤버별 health 도 확인.
- **Admin 콘솔 분리** — admin 전용 화면 별도 진입.
- **CLI `doctor` 명령** — 환경 자동 진단 + 복구.
- **셋업 환경 진단 카드** — `/setup-status` 에서 Node / codeburn / ccusage 버전 + 권한 한눈에.

## 🔧 개선

- 효율 점수 드릴다운 — 어떤 요소가 점수에 얼마나 기여하는지 분해 보기.
- 권한 사고 (EACCES) 자동 진단 + 해결 안내.

## ✨ 새 기능

- **멀티 회사 격리** — 한 시스템에서 N개 회사를 운영. 각 회사 데이터는 다른 회사와 완전 분리.
- **Mac 앱 (.dmg) Cloud Dashboard 진입점** — Mac 앱에서 `Cmd+2` 로 클라우드 대시보드 즉시 진입. OAuth in-window + 쿠키 영속.

## 🔧 개선

- 5명 install 전원 검증 — macOS 4명 + Windows 1명, 마지막 sync 1시간 내.
- LOCAL_MODE 도 multi-tenant 호환 — SQLite mirror schema 갱신.
- max20 사용자가 본인 Plan 을 직접 입력하는 UI (드롭다운).

## ✨ 새 기능

- **Plan Savings 카드 재설계** — Plan 없을 때 (API 종량제) vs 실제 Plan 비용을 빅 넘버 (`▼ $11,750`) + 비교 막대로 즉각 비교.
- **Top 토큰 사용자 카드** (admin 전용) — 우리 팀에서 토큰을 많이 쓰는 5명 순위 즉시 표시.

## 🔧 개선

- **Plan Health 평가 — 비용 기반으로 교체** — 옛 사용량 한도 (utilization%) 가 단위 불일치로 99,000% 같은 비현실 수치 보이던 버그 폐기. 이제 `월 API 환산 비용 ÷ Plan 가격` 비율로 평가.
- 한국어 친화 폰트 (Pretendard) + Tailwind 사이즈 +1px.
- 24주 활동 잔디 통일.

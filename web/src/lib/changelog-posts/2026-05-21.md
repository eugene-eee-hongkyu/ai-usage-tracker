## ✨ 새 기능

- **노트북 여러 대 동시 사용** — 한 사람이 노트북 2~3대를 같은 계정으로 쓸 수 있어요. 노트북마다 별도로 인증되고, 데이터는 자동으로 합쳐서 한 사용자로 표시됩니다.
- **회사 자동 가입** — 같은 이메일 도메인 (예: `@yourcompany.com`) 의 새 동료가 OAuth 로 로그인하면 별도 초대 없이 자동으로 팀에 들어옵니다. owner 가 끄고 켤 수 있어요 (세팅 → 자동 가입).
- **팀 비교 랭킹** — admin → Team → 랭킹. 최근 30일 다른 회사들과 활용지수·토큰 단가·Top 사용자를 익명화해서 비교합니다.
- **내 디바이스 관리** — 세팅 페이지에 등록된 노트북 목록 + 이름 변경 + 해제. OS·Node·Claude Code 버전도 함께 표시되어 문제 진단 가속.
- **어드민이 회사명 직접 정함** — 새로 가입한 어드민이 첫 로그인에 회사명을 본인이 입력하는 흐름.

## 🔧 개선

- 설치/업데이트 메시지 단순화 — 내부 디버그 정보 숨김, 무엇이 진행 중인지 한눈에.
- 헤더 재설계 — 화면 상단에 `[ADMIN] 회사명` 강조 표시.
- 팀 이름을 세팅에서 직접 변경 가능 (4~20자).
- 초대 모달 정리 — 역할에 따라 권한 체크박스가 자동으로 보이거나 숨겨짐.

## 🐛 수정

- 한 사람이 두 OAuth (다른 이메일) 로 가입돼서 두 명으로 잡히던 문제 — 통합 가이드 + 매뉴얼 통합 흐름 마련.
- 토큰 단가가 실제의 2배로 계산되던 버그.

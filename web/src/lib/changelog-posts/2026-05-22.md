## ✨ 새 기능

- **본전 회수 hero (이번 달)** — Plan 가격 대비 현재까지 누적 회수율 + 본전 돌파일 + 남은 기간 예상을 화면 상단에 즉시 표시. "내 요금제가 본전 뽑나" 의 직관적 답.
- **팀 내 내 위치 카드** — peer 비교. 같은 팀 안에서 cache hit·1-shot 비율의 내 순위가 한눈에.
- **팀 본전 회수 카드** — 팀 전체 Plan 합 대비 이번 달 비용 회수율 + Top 사용자. 멤버 모두에게 노출 (admin 한정 X).
- **비용 원인 Top 3** (개인 dashboard 메인) — 가장 비용이 많이 발생한 Project · Model · Activity 를 즉시 표시. 어디서 줄여야 할지 0 스크롤로 보임.
- **Cache Hit Streak** — Cache hit ≥ 90% 연속 일수 카운트. Efficiency 카드 옆에 🔥 와 함께.
- **회사별 멤버 cap (max_members)** — Platform Admin 이 회사별 활성 멤버 수 상한 설정. 초대·자동 가입 양쪽 가드.

## 🔧 개선

- Hero 띠 단순화 + 본인 행 highlight (팀 화면).
- 효율 점수 카드 강등 (자세히 보기 안으로) — main 은 본전 회수·팀 위치·비용 원인이 우선.
- 옛 EfficiencyScoreSection 의 cache·oneShot streak 카드 정리.

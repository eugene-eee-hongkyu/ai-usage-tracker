## ✨ 새 기능

- **노트북별 데이터 분리** — 같은 사용자가 Mac + Windows 같이 써도 각 노트북이 별개 row 로 정확히 표시. 옛 흐름은 마지막 ingest 가 이전 device 데이터를 덮어쓰던 문제.
- **CLI repair self-heal** — revoke 된 키로 install 재실행해도 옛 키 존재만 보고 silent skip 하던 흐름 fix. 401 확인 즉시 자동 init 으로 fallback. install.sh 한 줄로 자가 치유.
- **CLI OAuth 계정 명시** — init 완료 시 어떤 OAuth 계정으로 연결됐는지 콘솔에 표시. 의도와 다른 계정으로 들어왔으면 즉시 인지.

## 🔧 개선

- 팀 화면도 device 별 row 분리 — multi-device 사용자가 더 이상 한 행에 합산 안 됨. 차트는 user 단위 합산 유지 (frontend 정합성).
- BY MEMBER / TEAM TOTAL 차트가 비어 보이던 버그 — memberKey 정합성.
- React key 충돌로 multi-device user row 가 누적 표시되던 버그.

## ✨ 새 기능

- **All Teams 비교 화면** (Platform Admin) — 모든 팀의 활용지수·토큰 단가·본전 회수·industry 비교 4개 위젯 × 팀별. 활용지수 desc 정렬. 팀명 클릭으로 즉시 view-as 진입 후 /team.
- **About popover 에 빌드 SHA + stale page 경고** — Nav 우상단 `i` 클릭 시 Page (브라우저 캐시 SHA) / Server (최신 SHA) 동시 표시. 다르면 amber 경고 + 새로고침 버튼.
- **자동 versioning** — 매 push 마다 patch +1 자동. About popover 에 `v0.2.xxx` 형태로 즉시 표시. GitHub API Link 헤더로 누적 commit count 계산.

## 🔧 개선

- **Daily Cost / Activity 의 빈 날도 0 dimmed row 로 표시** — 옛 동작은 활성일만 표시해 "왜 그날만 빠져 있지?" 혼란. 이제 모든 날짜가 한 줄씩 + dim 이 정도가 차이.
- 비용 원인 Top 3 의 path 위치 — ellipsis 앞쪽으로 (긴 path 의 뒷부분 유지가 더 정보량).

## 🐛 수정

- view-as 모드에서 개인 dashboard 들어오면 자동 exit 되던 동작 → 안내 화면 + 수동 Exit 버튼. 의도적 view-as 가 풀리는 사고 방지.
- view-as 띠가 /team + /team/[userId] 에 안 보이던 누락 — 모든 admin 화면 일관성.

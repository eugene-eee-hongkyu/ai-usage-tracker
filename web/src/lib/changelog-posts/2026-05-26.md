## ✨ 새 기능

- **About popover 에 빌드 SHA + stale page 경고** — Nav 우상단 `i` 클릭 시 Page (브라우저 캐시 SHA) / Server (최신 SHA) 동시 표시. 다르면 amber 경고 + 새로고침 버튼.
- **자동 versioning** — 매 push 마다 patch +1 자동. About popover 에 `v0.2.xxx` 형태로 즉시 표시.

## 🔧 개선

- **Daily Cost / Activity 의 빈 날도 0 dimmed row 로 표시** — 옛 동작은 활성일만 표시해 "왜 그날만 빠져 있지?" 혼란. 이제 모든 날짜가 한 줄씩 + dim 이 정도가 차이.
- 비용 원인 Top 3 의 path 위치 — ellipsis 앞쪽으로 (긴 path 의 뒷부분 유지가 더 정보량).

## ✨ 새 기능

- **Personal 모드** — 도메인 제한 없이 누구나 GitHub / Google 로 즉시 가입 가능. 옛 흐름은 미리 등록된 회사 도메인만. 가입자는 자동으로 personal 풀에 들어와 글로벌 랭킹 참여.
- **전체 익명 랭킹** — 회사 무관 personal 사용자 전체의 5 metric 랭킹: **비용** · **사용량** · **연속 활성일** · **캐시 히트율** · **캐시 절약액**. 이름은 마스킹 (`e****u`), 본인은 강조.
- **랭킹 참여 토글** — 세팅 / Nav 에서 on/off. 회사 멤버는 default off, personal 사용자는 default on. confirm 팝업.
- **세팅 화면 신뢰 안내** — 오픈소스 GitHub 링크 + ai.z21labs.world 링크 + "메타데이터만 수집" 강조 카드.
- **로그인 화면 신뢰 안내** — GitHub repo + 랜딩 페이지 링크 + 한 OAuth 계정 유지 hint.

## 🔧 개선

- 랭킹 5 metric 재구성 — 옛 "활용지수" 제거 (계산 단위 불일치로 신뢰도 낮음), streak / 캐시 절약액 / Max20 회수율로 교체.
- 비용 카드 wide + 2x2 grid 레이아웃.
- 30일 윈도우 off-by-one 정정 + 활성일 컬럼 1줄.

- **정확성 라운드 4 일괄 (B/C/D/E)** — 누적 30+ fix: streak/monthRecovery/dwellHeatmap 의 KST/SGT timezone boundary, dashboard NaN 가드, 빈 날 표시, e2e helper schema 등.

## ✨ 새 기능

- **aiusage.z21labs.world 랜딩 페이지** — 첫 방문 (미인증) 시 hero + 3 가치 카드 + "시작하기" CTA + 푸터 링크 표시. 옛 동작은 즉시 /login 으로 떠밀려 "이게 뭐 하는 서비스인지" 모르는 상태였음. 인증된 사용자는 그대로 /dashboard 직행 (회귀 0).
- **마케팅 도메인 (ai.z21labs.world) 우상단 "대시보드 →" 버튼** — 마케팅 풀세트 본 후 한 클릭으로 본 앱. 새 탭에서 열려 마케팅 탭 유지.
- **개인 vs 팀 도입 분기** — 개인 사용자는 aiusage 슬림 랜딩, 팀 도입 검토자는 ai.z21labs.world 풀 마케팅. aiusage 랜딩 푸터에 "팀으로 도입 검토 중이시라면 → ai.z21labs.world" 분기 링크.

## 🔧 개선

- **로그인된 사용자가 /login 직접 진입 시 즉시 /dashboard 직행** — 옛 동작은 client-side 만 LOCAL_MODE redirect, NextAuth 세션 있어도 로그인 화면 그대로 보임. 서버 단 세션 검사 추가.
- 본인 OAuth 가입 provider 영구 lock — 처음 GitHub 으로 가입했으면 GitHub 로만, Google 로 가입했으면 Google 로만. 다른 provider 시도 시 명시 메시지로 안내 (계정 탈취 방어).
- 로컬 dev 환경 / 빌드 산출물 정리, `cli/src/index.mjs` 실행 비트 보정.

## 🐛 수정

- `/api/auth/verify` 의 응답 body 가 module-level 상수로 캐싱되어 두 번째 요청부터 빈 body 가 나오던 회귀.

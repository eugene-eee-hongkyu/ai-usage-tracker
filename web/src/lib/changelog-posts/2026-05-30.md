## ✨ 새 기능

- **Codex provider 정식 추가** — Claude 와 함께 Codex 사용량도 같은 dashboard 에서 추적. provider 토글로 전환. cost / 토큰 / cache hit / oneShot / activity heatmap 등 모든 metric 이 Codex 에도 동일 적용.
- **Multi-device 합산 모드** — 한 사용자가 여러 노트북에서 작업할 때 device chip 옆 "합산" 버튼으로 모든 device 데이터를 한 view 에 합쳐 보기.

## 🔧 개선

- **CLI v0.3.2 권장 버전 batch** — Codex 지원 + partial submit 허용 + telemetry buffer + provider 직렬 호출. dashboard 상단 업데이트 배너 안내.
- **정확성 라운드** — cost 계산이 hero / chart / Plan 모두 같은 출처 (ccusage daily 합산) 로 통일. period=month 의 monthRecovery 일자 범위 정정, 8일 plan 절감 잘못된 분모 fix, multi-device 사용자가 admin 멤버 dropdown 에 device 별로 중복 표시되던 회귀 등 누적 정정.

## 🐛 수정

- **이번달 / 30일 / 전체 사용량이 0 으로 보이던 회귀** — codeburn 일부 period 호출 실패 시 살아있는 period 자료까지 같이 누락되던 흐름. 이제 partial 이라도 가진 자료는 보존하고 실패 정보는 telemetry 로 진단.
- **팀 내 내 위치 카드** — 다른 OAuth provider name 으로 매칭되어 본인 카드가 안 보이던 회귀. DB users.name 으로 통일.

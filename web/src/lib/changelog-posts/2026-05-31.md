## 🔧 개선

- **자동 수집 주기 2시간 → 1시간** — Mac (launchd) / Windows (Task Scheduler) 모두 통일. 더 fresh 한 데이터, sleep 후 깨어나도 즉시 보충. 기존 사용자는 dashboard 상단 CLI 업데이트 배너 안내 따라 `npx ... repair` 한 번 실행 시 새 schedule 로 자동 교체.

- **today / 8일 / 이번달 화면 단순화 (개인 + 팀)** — 표본 작은 짧은 period 에 의미 약한 카드 hide:
  - 개인 대시보드: By Model / By Project / Top Sessions / By Activity / MCP Servers / Efficiency 6 카드. Overview Bar 의 1-shot 표시도 같이 제거. 핵심 두 카드만 표시 (비용 원인 Top 3 + Cache Hit Streak / 체류 히트맵).
  - 팀 화면: Efficiency / Team Activities / By Model / (admin 한정) Top Sessions 4 카드.
  - 30일 / 전체 기간은 기존 그대로.

- **데이터 수집·저장 백엔드 정리** — 더 이상 안 쓰는 metric / 테이블 / legacy fallback 일괄 제거 (CLI ↔ 서버 ↔ DB 전 구간). 부수 효과로 활용도 낮던 Core Tools / Shell Commands 카드도 사라짐.

- **multi-device 사용자 표시 정상화** — 한 사용자가 여러 노트북에서 작업할 때 멤버 카드들이 device 별로 N row 로 보이던 회귀 → userId 단위 1행 dedup.

## 🐛 수정

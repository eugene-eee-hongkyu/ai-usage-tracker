## 🔧 개선

- **ccusage 19.0.2 → 20.0.6** — Rust 네이티브 백엔드 + sidechain dedup. 3 사용자 검증으로 schema 호환 + 수치 변동 미미 (±0.2%) 확인.
- **codeburn 0.9.7 → 0.9.11** — **Anthropic 의 1-hour cache write 가격 정정** (1.25x → 2x base input, Anthropic 공식 가격 반영). 사용자별 codeburn cost 표시가 +5~20% 증가하지만 (cache write 비율에 비례), **dashboard 의 cost 표시 자체는 ccusage 출처라 영향 거의 없음**. codex subagent dedup 으로 codex cost 는 약 −3~5%.
- **일별 oneShotRate 가 처음으로 실제 값** — codeburn 0.9.8 부터 daily row 에 `turns / oneShotTurns / oneShotRate` 추가 (PR #279). dashboard 의 일별 efficiency 패널이 옛 null 에서 실제 값으로 채워짐.
- **CLI 0.3.4** — 위 핀 갱신 + 검증 도구 `compat-check` 신설 (운영용). dashboard 상단 CLI 업데이트 배너 따라 install.sh 한 번 실행 시 새 ccusage / codeburn 자동 설치.
